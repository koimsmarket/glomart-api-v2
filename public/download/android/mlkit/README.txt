Glomart ML Kit translation language download catalog

- languages.json: all Google ML Kit Translation supported languages.
- primary25.json: Glomart 25-country mapping and ML Kit support status.
- lang/<code>.json: per-language download descriptor.

IMPORTANT
The actual Google ML Kit translation model binaries are NOT copied to this server.
The Glomart Android app calls ML Kit on the device to download the selected model.
This is the supported delivery mechanism for ML Kit dynamic translation models.
