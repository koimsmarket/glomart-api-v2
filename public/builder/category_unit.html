카테고리 단위가격 자동분석

대표단위 판정은 gm_category + gm_product만 사용합니다. gm_product_option은 이번 판정에서 제외하며, 카테고리 기준 확정 후 상품+옵션 단위가격 재계산 단계에서만 사용합니다. 중량/용량이 혼재하면 상품 건수가 많은 쪽을 자동 선택합니다.
A

AI API 연결

카테고리 AI 분류를 실행하기 전에 OpenAI API 연결만 확인합니다. 이 테스트는 1회 소량 요청만 보내며 DB의 카테고리 데이터는 수정하지 않습니다.



B
AI 과금 안전설정
값은 gm_runtime_config에 저장되며 재배포 없이 다음 AI 호출부터 바로 적용됩니다. OpenAI 조직 한도보다 서버 월 예산을 낮게 두는 것을 권장합니다.


 사용


 AI 전체 중단
ON이면 모든 AI 호출 차단


























1
카테고리 + 상품 전체 분석
DB는 수정하지 않습니다. 쿠팡 상품명에서 kg·g·L·ml·정·매·롤·켤레 표기를 분석합니다. 옵션은 판정 근거에 넣지 않습니다.


2
예외 분석
중량/용량 혼재는 많은 쪽으로 자동 정리합니다. 여기에는 카테고리 미매칭과 중량·용량 완전 동률만 남깁니다.
선택 0건
키워드상태상품수중량/용량정규화 후보대표 상품 예시AI 추천 카테고리신뢰도AI 근거
1번 전체 자동분석을 먼저 실행하세요.


3
분석 결과 자동 적용
현재 DB를 다시 분석하여 기존 gm_category.unit_rule_qty / unit_rule_unit에 바로 적용합니다. 별도 CSV/단위룰 DB는 만들지 않습니다.
미매칭은 적용할 gm_category 행이 없어 건너뜁니다. 중량/용량 완전 동률도 자동 적용하지 않습니다. 나머지 혼재는 상품 건수가 많은 쪽으로 자동 적용됩니다.


4
상품 + 옵션 단위가격
대표단위 확정 후 실행합니다. 이 단계부터 옵션을 포함하며 500g×2, 120g×5, 330ml×24 같은 복합표현도 같은 계산엔진으로 처리합니다.
