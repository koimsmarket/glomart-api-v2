카테고리 단위가격 자동분석

대표단위 판정은 gm_category + gm_product만 사용합니다. gm_product_option은 이번 판정에서 제외하며, 카테고리 기준 확정 후 상품+옵션 단위가격 재계산 단계에서만 사용합니다. 중량/용량이 혼재하면 한쪽으로 강제 통일하지 않고 MIXED로 유지합니다. 이후 상품 단위가격 계산에서 각 상품의 원래 중량/용량 계열을 그대로 사용합니다.
A

AI API 연결

카테고리 AI 분류를 실행하기 전에 OpenAI API 연결만 확인합니다. 이 테스트는 1회 소량 요청만 보내며 DB의 카테고리 데이터는 수정하지 않습니다.



B
AI 과금 안전설정
값은 gm_runtime_config에 저장되며 재배포 없이 다음 AI 호출부터 바로 적용됩니다. OpenAI 조직 한도보다 서버 월 예산을 낮게 두는 것을 권장합니다.

1
카테고리 + 상품 전체 분석
전체 분석 시작 시 gm_product의 과거 다국어 keyword/category_keyword는 기존 방식대로 한국어 정제합니다. 단위 기준 카테고리 매칭은 문자열 keyword가 아니라 상품의 첫 번째 glomart_code → gm_category.gm_code로 직접 연결합니다. glomart_code 미부여 상품은 분석 대상에서 제외하고 참고 숫자로만 표시하며, 첫 glomart_code가 실제 gm_category에 없는 경우만 실제 미매칭으로 남깁니다. 옵션은 판정 근거에 넣지 않습니다.


2
예외 분석
중량/용량 혼재는 정상 상태로 보고 예외로 보내지 않습니다. 여기에는 실제 존재하지 않는 gm_code만 남깁니다. 오겹살→삼겹살처럼 기존 카테고리로 귀속할 수 있으면 관리자 수동 연결에서 카테고리를 검색해 선택합니다. 적용 시 해당 상품들의 첫 glomart_code만 선택한 gm_code로 교체하며 뒤의 다른 코드는 보존합니다.

1번 전체 자동분석을 먼저 실행하세요.


3
분석 결과 자동 적용
현재 DB를 다시 분석하여 기존 gm_category.unit_rule_qty / unit_rule_unit에 바로 적용합니다. 별도 CSV/단위룰 DB는 만들지 않습니다.
실제 미매칭 코드는 적용할 gm_category 행이 없어 건너뜁니다. 중량/용량 혼재 카테고리는 MIXED로 적용하며, 상품 단계에서 중량은 중량대로·용량은 용량대로 계산합니다.


4
상품 + 옵션 단위가격
대표단위 확정 후 실행합니다. 상품의 glomart_code가 여러 개면 첫 번째 코드만 사용하여 gm_category.gm_code와 매칭합니다. 일반 카테고리는 unit_rule_qty / unit_rule_unit을 그대로 사용하고, MIXED 카테고리는 쿠팡 unit_price_text의 원래 단위계열을 우선 사용하여 중량은 100g 기준, 용량은 100ml 기준으로 정규화해 정렬값을 만듭니다. 원래 unit_price_text는 표시용으로 그대로 보존합니다. category_keyword는 기준 선택에 사용하지 않습니다.
