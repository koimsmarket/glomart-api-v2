카테고리 단위가격 자동분석

CSV나 별도 단위룰 DB를 관리하지 않습니다. 현재 gm_category + gm_product + gm_product_option을 직접 분석하여 카테고리 대표단위를 계산합니다. 옵션은 부모 상품의 분석근거에 합치되 옵션이 많은 상품이 과대반영되지 않도록 상품 1개당 1표로 계산합니다.
1

카테고리 + 상품 + 옵션 전체 분석

DB는 수정하지 않습니다. 카테고리 정확매칭 여부와 쿠팡 상품/옵션의 kg·g·L·ml·정·매·롤·켤레 표기를 분석해 대표단위를 자동 제안합니다.






2


분석 결과 자동 적용


분석을 다시 실행한 현재 결과를 기존 gm_category.unit_rule_qty / unit_rule_unit 두 칼럼에 바로 적용합니다. 별도 테이블이나 CSV는 만들지 않습니다.


중량·용량이 함께 강하게 나타나는 혼합 카테고리는 자동 적용 시 보수적으로 1개 기준을 사용합니다. 카테고리와 정확히 연결되지 않는 검색키워드는 적용할 gm_category 행이 없으므로 건너뜁니다.










3


상품 + 옵션 단위가격


카테고리 대표단위 적용 후 실행합니다. 500g×2, 120g×5, 330ml×24 같은 복합표현을 포함해 상품과 옵션을 같은 계산엔진으로 처리합니다.
