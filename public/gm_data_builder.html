PRODUCT GLOMART_CODE MATCH

gm_category의 gm_code를 상품의 glomart_code에 채웁니다. 먼저 과거 상품의 외국어 검색 키워드를 기존 번역/검색 canonical/카테고리 다국어명으로 한국어 기준어로 정제한 뒤 다시 매칭합니다. 검색 로그의 사용자가 입력한 원문은 수정하지 않습니다. 직접 코드 → mall_category/cp_code → 기존 정상상품 이력 → 카테고리 keyword 정확/토큰일치 순으로 판정하며 기존 glomart_code는 덮어쓰지 않습니다.

FD / HS 6세그먼트 카테고리 교체 업로드

번역까지 완료된 최종 FD/HS CSV를 사용합니다. 기존 행은 category_id를 유지한 채 6세그먼트 코드·부모·다국어명을 갱신하고, 신규 행만 INSERT합니다. 현재 FD/HS 기존 category_id가 CSV에 하나라도 빠지면 적용을 거부합니다. 일반 Safe Update 대신 이 기능을 사용합니다.

최종 CSV를 선택한 뒤 반드시 검증부터 실행하세요.

FD / HS 6단계 전환 재매칭

식품(FD)·생활용품(HS) 카테고리 구조를 6단계로 교체한 뒤 사용합니다. 현재 glomart_code에 FD 또는 HS가 들어 있는 상품만 대상으로 하며, 후보 카테고리도 현재 gm_category의 6세그먼트 FD/HS 코드만 사용합니다. 일반 glomart_code 적용의 “기존값 보호” 정책은 그대로 유지됩니다.

미분류 이상 키워드 상품 정리

검색 0~1회는 후보를 좁히는 조건일 뿐 자동 삭제 기준이 아닙니다. 말이 안 되는 STT/명령문 등 이상 키워드만 직접 선택합니다. 선택한 키워드에 연결된 glomart_code 미분류 상품 중 주문·판매·장바구니·찜 이력이 전혀 없는 상품만 삭제하며, 이력이 있는 상품은 서버에서 재확인해 자동 보호합니다.
