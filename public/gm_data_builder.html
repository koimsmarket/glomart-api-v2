미수행 Queue 업로드

product_uid / image_url / updated_at CSV 또는 Excel을 업로드합니다. 기존 Queue는 삭제하지 않고 UID 기준으로 추가·갱신합니다.

IMAGE VECTOR CATEGORY GROUP

Image Vector 전용 모듈이 직접 처리합니다. 공용 Safe Update를 경유하지 않습니다. CSV는 product_uid,category_group 두 컬럼만 허용하며, 기존 Vector UID만 UPDATE합니다. vector_image / candidate_vector / class_id는 변경하지 않습니다. 최대 200,000행, DB는 10,000행 단위 batch 처리합니다.

IMAGE VECTOR CLASSIFICATION

대분류 스페셜 작업 완료 시 실행하는 주기적 재분류입니다. 먼저 STAGING에 카테고리와 PUID→카테고리코드를 모두 만든 뒤 검증하고, APPLY 때만 운영 DB에 함께 반영합니다. STAGING은 APPLY 후에도 보존되며 다음 분류 시작 직전 자동 삭제됩니다. 필요하면 수동 삭제할 수 있습니다.
